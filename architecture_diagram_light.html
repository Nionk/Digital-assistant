3. База данных (PostgreSQL 16)
Реляционная схема 9 таблиц
Структурированное хранение сущностей:
  • events: мероприятия, даты, регламенты
  • event_tariffs: роли (delegate, speaker), цены
  • clients: компании, профили, конспекты созвонов
  • selections & items: подборки и варианты
  • chat_messages: протокол вопросов и эскалаций
pgvector HNSW Индекс 1024-dim
Векторный поиск по смысловой близости:
  • Косинусное расстояние (<=>) с L2-нормализацией
  • Индексация summary_embedding описаний событий
FTS GIN Индекс tsvector
Полнотекстовый поиск по отраслевым терминам:
  • Точный поиск аббревиатур девелопмента (КРТ, ИЖС)
  • Комбинирование рангов по формуле RRF (k=60)
Таблица llm_cache SHA-256
Точный хэш-кэш проверенных ответов RAG:
  • Мгновенный ответ клиенту за < 50 мс без вызова LLM
  • Автоматическая инвалидация при обновлении тарифа
🛡️ Единое хранилище: ACID транзакции, отказ от Redis, нулевые потери данных
