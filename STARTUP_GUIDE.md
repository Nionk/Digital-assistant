# 🚀 Пошаговое руководство: Как запустить проект с нуля до работающего сайта

> **Для кого эта инструкция:** для любого человека, даже если вы никогда раньше не запускали веб-приложения, серверы, базы данных и не работали с консолью.  
> Здесь всё разложено буквально «по шагам», с разбором возможных ошибок и готовыми командами, которые нужно просто скопировать и вставить.

---

## 🧭 Что мы запускаем и как это устроено (на пальцах)

Наш проект **Digital Assistant** состоит из трёх ключевых частей, которые работают сообща:

```
┌────────────────────────────────────────────────────────┐
│  1. База данных (PostgreSQL + pgvector)                │
│     Хранит все мероприятия, тарифы, клиентов и векторные│
│     эмбеддинги для умного поиска.                      │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│  2. Бэкенд-сервер (FastAPI, Python 3.12)               │
│     Мозг системы. Считает бюджеты, подбирает пакеты,    │
│     общается с нейросетями (LLM), шлет алерты в ТГ.    │
│     Работает на адресе: http://localhost:8000          │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│  3. Фронтенд-интерфейс (React + Vite + Tailwind CSS)   │
│     Красивый сайт в браузере (кабинет менеджера +      │
│     публичная витрина для клиента).                    │
│     Работает на адресе: http://localhost:5173          │
└────────────────────────────────────────────────────────┘
```

Базу данных и Бэкенд мы запустим в **Docker** (он упакует их сам, чтобы вам не пришлось ставить кучу сложных библиотек), а Фронтенд запустим через **Node.js**.

---

## 🛠️ Шаг 0. Что должно быть установлено на компьютере (Делается 1 раз)

Перед тем как начать, убедитесь, что на вашем компьютере установлены три бесплатные программы:

### 1. Git (программа для скачивания кода)
* **Зачем нужен:** чтобы скачать проект с GitHub и обновлять его.
* **Где скачать:** [https://git-scm.com/downloads](https://git-scm.com/downloads) (скачайте установщик для Windows или Mac, при установке нажимайте всё время «Next»).

### 2. Docker Desktop (виртуальный контейнер для сервера и базы данных)
* **Зачем нужен:** чтобы запустить базу данных PostgreSQL и сервер Python буквально одной командой.
* **Где скачать:** [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
* ⚠️ **Важно для Windows:** 
  - Во время установки согласитесь на использование **WSL 2** (Use WSL 2 instead of Hyper-V).
  - После установки запустите **Docker Desktop** из меню «Пуск».
  - Подождите 1–2 минуты, пока значок «кита» в левом нижнем углу окна Docker станет **зеленым** (статус: *Engine running*). Без запущенного Docker Desktop сервер не запустится!

### 3. Node.js (платформа для запуска фронтенда)
* **Зачем нужен:** чтобы собрать и отобразить интерфейс сайта в вашем браузере.
* **Где скачать:** [https://nodejs.org/](https://nodejs.org/) (скачайте версию с пометкой **LTS** — например, v20 или v22).

---

### 🔍 Как проверить, что всё установлено правильно?

1. Откройте **Терминал** на компьютере:
   - В Windows: нажмите комбинацию клавиш `Win + R`, введите `cmd` (или `powershell`) и нажмите **Enter**.
   - В macOS: нажмите `Cmd + Пробел`, введите `Terminal` и нажмите **Enter**.
2. По очереди введите следующие команды и нажмите Enter после каждой:

```bash
git --version
docker --version
node -v
npm -v
```

Если в ответ выводятся номера версий (например, `git version 2.45...`, `Docker version 27...`, `v20.18...`), поздравляем — ваш компьютер полностью готов!

## 📥 Шаг 1. Скачиваем проект к себе на компьютер

1. Выберите папку на компьютере, куда хотите скачать проект (например, создайте папку `C:\Projects` в Windows или откройте домашнюю папку в macOS).
2. Чтобы быстро открыть терминал прямо в нужной папке в Windows:
   - Откройте папку в Проводнике.
   - Кликните мышкой в **адресную строку** проводника (сверху, где написан путь к папке).
   - Сотрите путь, напечатайте `cmd` и нажмите **Enter**. Откроется чёрное окно консоли ровно в этой папке.
3. Введите команду для скачивания (клонирования) проекта:

```bash
git clone https://github.com/Nionk/Digital-assistant.git
```

4. Дождитесь окончания загрузки (10–30 секунд). Затем перейдите внутрь скачанной папки проекта:

```bash
cd Digital-assistant
```

  ```powershell
  copy .env.example .env
  ```

  ```bash
  cp .env.example .env
  ```

## 🐳 Шаг 3. Запуск сервера и базы данных (Бэкенд)

> ⚠️ **Проверьте:** приложение **Docker Desktop** должно быть запущено на вашем компьютере перед выполнением этой команды!

1. В окне терминала, находясь в корневой папке `Digital-assistant`, выполните команду:

```bash
docker compose up -d --build
```

### Что сейчас произойдет:
- Docker автоматически скачает образ базы данных с поддержкой векторов (`pgvector`).
- Автоматически соберет контейнер бэкенда на Python 3.12 со всеми зависимостями.
- Запустит оба сервиса в фоновом режиме (`-d`).
- Первый запуск может занять 1–3 минуты (скачиваются пакеты). При повторных запусках это будет занимать 2 секунды.

### Как проверить, что сервер успешно запустился:
Откройте ваш обычный браузер (Chrome, Яндекс, Edge) и перейдите по ссылкам:
- 🔗 **Проверка здоровья:** [http://localhost:8000/health](http://localhost:8000/health)  
  *Вы должны увидеть на экране короткий ответ:* `{"status":"ok"}`.
- 🔗 **Интерактивная документация Swagger API:** [http://localhost:8000/docs](http://localhost:8000/docs)  
  *Откроется страница со списком всех эндпоинтов системы.*

Если страницы открылись — бэкенд и база данных работают идеально!

## 🗄️ Шаг 4. Наполнение базы данных мероприятиями и клиентами (Сидинг)

Новая база данных сейчас пустая. Нам нужно создать в ней таблицы и загрузить начальные данные: **15 выставок и форумов**, тарифы, дедлайны, векторные эмбеддинги и тестовых клиентов (ГК «Пионер», «Девелопмент-Юг», «Брусника»).

Выполните в терминале всего две команды по очереди:

### Команда 1: Создание таблиц (миграции Alembic)
```bash
docker compose exec backend alembic upgrade head
```
*Что произойдет:* в базе данных создадутся все 9 необходимых таблиц, внешние ключи и векторные индексы. В конце появится надпись `Running upgrade ... -> ...`.

### Команда 2: Загрузка мероприятий и клиентов (Сидинг)
```bash
docker compose exec backend python scripts/seed_db.py
```
*Что произойдет:* скрипт создаст аккаунт менеджера, загрузит 3 клиентов с историей переговоров и 15 деловых мероприятий со всеми тарифами.  
В конце вы увидите подтверждение:
```
[OK] Успешно сидировано: 15 мероприятий, 43 тарифов, 60 записей llm_cache.
======================================================================
Сидинг успешно завершен! Создано/проверено: 1 менеджер, 3 клиента, 15 мероприятий.
======================================================================
```

## 💻 Шаг 5. Запуск веб-интерфейса (Фронтенд)

Теперь оживим визуальный интерфейс, на который мы будем смотреть в браузере.

1. **Откройте новое окно терминала** (или новую вкладку в вашей консоли).
2. Перейдите в папку `Digital-assistant/frontend`:
   ```bash
   cd Digital-assistant/frontend
   ```
   *(Если вы уже находитесь в `Digital-assistant`, просто напишите `cd frontend`).*

3. Установите библиотеки фронтенда (делается только при первом запуске):
   ```bash
   npm install
   ```
   *Подождите около 1 минуты, пока установятся React, Tailwind и анимации.*

4. Запустите сайт в режиме разработки:
   ```bash
   npm run dev
   ```

5. На экране появится надпись зеленым шрифтом:
   ```
     VITE v6.4.5  ready in 450 ms

     ➜  Local:   http://localhost:5173/
     ➜  Network: use --host to expose
     ➜  press h + enter to show help
   ```

**Готово!** Сервер фронтенда работает и автоматически перенаправляет запросы к бэкенду. Окно консоли **не закрывайте** — пока оно открыто, сайт доступен в браузере.

## 🌐 Шаг 6. Открываем сайт и пробуем функционал

Откройте ваш браузер и перейдите по адресу:
👉 **[http://localhost:5173](http://localhost:5173)** (или [http://localhost:5173/admin](http://localhost:5173/admin))

Перед вами откроется полноценная рабочая станция:

### 1. Вкладка «База площадок»:
- Полный каталог всех 15 отраслевых мероприятий с ценами, городами и датами.
- Поиск по ключевым словам и фильтрация по форматам (Форум, Конференция, Выставка, Круглый стол...).
- Клик по любой карточке открывает правую **шторку с подробными условиями площадки**, тарифами участия, контактами оргкомитета и точным адресом.
- В верхней панели отображаются **«Дедлайны Early Bird»** (мероприятия с горящими скидками на раннюю регистрацию) — кликните на любое из них, чтобы мгновенно открыть его условия!

### 2. Вкладка «Подбор клиентов»:
- В левой колонке выберите клиента, например **ГК «Пионер»** или **«Брусника»**.
- Система отобразит исходные заметки менеджера после звонка и распознанный профиль клиента (бюджет, роли спикеров/делегатов, желаемые города).
- Нажмите кнопку **«Собрать коммерческое предложение»** — алгоритм сбалансирует пакет площадок под потолок бюджета клиента.
- Нажмите **«Опубликовать витрину для клиента»** — сгенерируется персональная зашифрованная ссылка для клиента и скопируется в буфер обмена.

### 3. Интерактивная витрина клиента:
- Откройте сгенерированную ссылку в соседней вкладке (или режиме инкогнито), она имеет вид:  
  `http://localhost:5173/s/любой-токен`
- Клиент видит презентабельный лендинг с атмосферным архитектурным фоном, расчетом экономии, карточками предложенных мероприятий и интерактивным чатом **«ИИ-консультант по регламентам»**.
- Если клиент нажимает «Согласовать участие» или «Запросить замену», менеджеру в Telegram мгновенно прилетает живое уведомление через настроенного бота!

## 🔄 Шаг 7. Как выключать и запускать проект в следующие дни

Вам больше не потребуется ничего устанавливать или клонировать!

### Как остановить проект в конце рабочего дня:
1. В окне терминала с фронтендом нажмите комбинацию клавиш `Ctrl + C` (подтвердите остановку, нажав `Y` и `Enter`).
2. В окне терминала с бэкендом выполните команду:
   ```bash
   docker compose stop
   ```
   *(Или просто закройте Docker Desktop).*

### Как запустить проект завтра утром за 10 секунд:
1. Убедитесь, что **Docker Desktop** запущен.
2. В первом терминале (в папке `Digital-assistant`):
   ```bash
   docker compose start
   ```
3. Во втором терминале (в папке `Digital-assistant/frontend`):
   ```bash
   npm run dev
   ```
4. Откройте в браузере [http://localhost:5173](http://localhost:5173). Всё снова работает!

## 🛠️ Шаг 8. Альтернативный запуск БЕЗ Docker (если Docker не ставится)

Если ваш компьютер не поддерживает виртуализацию или Docker Desktop по каким-то причинам не запускается, вы можете запустить проект напрямую в системе:

<details>
<summary>▶ Нажмите сюда, чтобы развернуть инструкцию без Docker</summary>

### 1. Установите локально:
- **Python 3.12:** с [python.org](https://www.python.org/) (обязательно поставьте галочку «Add python.exe to PATH»).
- **PostgreSQL 16:** с [postgresql.org](https://www.postgresql.org/). При установке задайте пароль `scart_secret_password` и создайте базу данных `scart_db`.
- Установите расширение `pgvector` в PostgreSQL.

### 2. Запуск Бэкенда:
В терминале в папке `Digital-assistant/backend`:
```bash
# Создаем виртуальное окружение Python
python -m venv venv

# Активируем его
# В Windows:
.\venv\Scripts\activate
# В macOS / Linux:
source venv/bin/activate

# Устанавливаем библиотеки
pip install -r requirements.txt

# Применяем миграции и сидим данные
alembic upgrade head
python scripts/seed_db.py

# Запускаем сервер
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Запуск Фронтенда:
Во втором окне терминала в папке `Digital-assistant/frontend`:
```bash
npm install
npm run dev
```

## 🚑 Разбор частых проблем и ошибок (Troubleshooting)

### ❓ Проблема 1: Пишет `'docker' is not recognized as an internal or external command` (команда не найдена)
* **Причина:** Docker Desktop не установлен либо после установки терминал не был перезапущен.
* **Решение:** Установите Docker Desktop, запустите его, затем **полностью закройте окно терминала и откройте новое**.

---

### ❓ Проблема 2: Пишет `Cannot connect to the Docker daemon`
* **Причина:** Docker Desktop установлен, но сама программа сейчас выключена.
* **Решение:** Найдите в меню «Пуск» (или в Applications на Mac) ярлык **Docker Desktop** и запустите его. Дождитесь, пока значок в левом нижнем углу окна Docker станет зеленым.

---

### ❓ Проблема 3: Порт уже занят: `Bind for 0.0.0.0:8000 failed: port is already allocated`
* **Причина:** Порт 8000 (или 5432) уже занят другой программой или ранее запущенным контейнером.
* **Решение:**
  1. Выполните команду `docker compose down`, чтобы остановить старые зависшие контейнеры.
  2. Если не помогло, в Windows найдите, кто занял порт:
     ```powershell
     netstat -ano | findstr :8000
     ```
     И завершите процесс через Диспетчер задач, либо просто перезагрузите компьютер.

---

### ❓ Проблема 4: В браузере на `localhost:5173` пусто, крутится бесконечная загрузка или пишет «Ошибка сети»
* **Причина:** Фронтенд запущен, но бэкенд на порту 8000 не отвечает.
* **Решение:**
  1. Проверьте в браузере ссылку [http://localhost:8000/health](http://localhost:8000/health).
  2. Если страница не открывается, посмотрите логи бэкенда командой:
     ```bash
     docker compose logs backend
     ```
  3. Перезапустите контейнеры:
     ```bash
     docker compose restart backend
     ```

---

### ❓ Проблема 5: В каталоге пишет «0 мероприятий» или клиентов нет в списке
* **Причина:** Вы забыли выполнить шаг 4 (сидинг базы данных).
* **Решение:** Выполните в терминале команду:
  ```bash
  docker compose exec backend python scripts/seed_db.py
  ```
  После успешного выполнения обновите страницу в браузере клавишей `F5`.

---

### ❓ Проблема 6: При выполнении `npm install` сыпятся красные ошибки с правами доступа
* **Причина:** Не хватает прав или заблокирован кэш npm.
* **Решение:**
  1. Закройте терминал.
  2. Откройте терминал **от имени Администратора** (правой кнопкой мыши по меню «Пуск» -> *Терминал (Администратор)* или *Командная строка (Администратор)*).
  3. Выполните:
     ```bash
     npm cache clean --force
     npm install
     ```
